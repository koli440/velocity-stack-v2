Chainring and cog now use the same two-field input on every screen, with a live ratio, gear inches and development readout.

- The preset dropdown in "Edit activity" is gone; type any gear you ride.
- Gear stays optional: leave it empty and nothing is assumed or saved. New uploads and imports start from your saved default gear only if you set one.
